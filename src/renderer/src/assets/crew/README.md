# Crew portraits

The avatars offered when you create an agent. Sliced from a single sheet into
256×256 tiles by `scripts/slice-crew.mjs`; re-run `npm run crew:slice <sheet.png>`
to regenerate. Ids must match `CREW_PORTRAITS` in `src/renderer/src/lib/crew.ts`.

> [!IMPORTANT]
> **The origin of this artwork is not recorded, and its distribution rights have
> not been established.**
>
> The source sheet is not in this repository and no licence, author or purchase
> record accompanies these files. Nobody has yet confirmed that the project may
> redistribute them, and their presence here is not a claim that it may.
>
> This has to be settled alongside any licensing decision. A repository licence
> is normally read as covering the repository's contents, so if these files stay
> they need either established rights or an explicit exclusion in the licensing
> notes. Whether they may be distributed here at all is the prior question.
>
> The options are to establish ownership, to exclude the assets explicitly, to
> replace the set with artwork whose licence is documented, or to remove it and
> fall back to generated avatars.
